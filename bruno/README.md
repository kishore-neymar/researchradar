# ResearchRadar Bruno API Collection

The Bruno collection documents every ResearchRadar API endpoint, organized by feature area.

## Setup

1. Install [Bruno](https://www.usebruno.com/) and open this repository.
2. Open `bruno/ResearchRadar` as a collection.
3. Select the `local` environment.
4. Start the server from the `server` directory with `npm run dev`.
5. Set `{{token}}` after calling the register or login request.
6. Replace ID variables with IDs returned by the API.

The collection includes health, authentication, user, opportunity, trend, saved-opportunity, and file-upload requests.
